# Customer Journey Analytics Dashboard

An end-to-end industry-oriented data analytics project that analyzes customer behaviour, purchasing patterns, traffic sources, conversion rates, and revenue performance using Python, MySQL, and Power BI.

---

## 📊 Project Overview

The **Customer Journey Analytics Dashboard** is designed to understand how customers interact with an e-commerce platform throughout their journey — from session activity and traffic source to purchase behaviour, payment method, product category, and revenue generation.

The project follows a complete analytics workflow:

**Raw Data → Data Understanding → Data Profiling → Data Cleaning & Transformation → Validation → MySQL → SQL Analysis → Power BI Dashboard → Insights & Recommendations**

---

## 🎯 Project Objectives

- Analyze customer purchasing behaviour
- Compare new and returning customer performance
- Evaluate traffic sources and conversion rates
- Analyze product category performance
- Identify revenue-generating categories and channels
- Understand payment method usage
- Compare device-level customer activity
- Build an interactive Power BI dashboard
- Generate actionable business insights

---

## 🗂️ Dataset

The final analytical dataset contains:

- **Records:** 5,982
- **Columns:** 27
- **Domain:** E-commerce Customer Journey Analytics

The analysis uses the cleaned dataset containing 5,982 records.
